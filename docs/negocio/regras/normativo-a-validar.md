## Regras que saíram

O ID não volta a ser usado. Ficam aqui para quem procurar um ID antigo.

|---|---|---|
| RN-06 | Registro de turnos | Virou cadastro de turnos (RN-01). |

| RN-31 | A escala exibida fica sincronizada com a tabela de alocações | Problema da planilha: no sistema novo há uma fonte só, o banco. |
| RN-95 | Se a cota conta para a meta de ativação é atributo da cota | O campo saiu em 20/11/2026: todo serviço conta para a meta. |
